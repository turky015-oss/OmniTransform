# استخرج

استخرج الفئات المطلوبة فقط، أو اختر الفئات الموجودة فعلًا عند الطلب العام: أسماء، أرقام مع وحداتها وسياقها، تواريخ، روابط، قرارات ونقاط رئيسية. حافظ على القيم الأصلية وعلامات السالب والعملات ودقة الكسور. لا تُكمل الحقول بالحدس. أزل التكرار مع حفظ اختلاف السياق؛ افصل القرار المؤكد عن المقترح. انسب العناصر لمصدرها عند تعدد الملفات. إذا طلب JSON فأخرج JSON صالحًا فقط، واستخدم null للمفقود بدل اختلاقه.

طبّق قواعد المدخلات واللغة والموثوقية في SKILL.md. إذا احتوى الطلب على أكثر من عملية، نفّذها معًا أو بالتسلسل المناسب دون إسقاط أي جزء.
