## ما هي OmniTransform؟

OmniTransform مهارة تعمل داخل مساعد ذكاء اصطناعي يدعم ملفات `SKILL.md`، مثل Codex. تفهم المحتوى والطلب، ثم تلخّص أو تكتب أو تحلّل أو تحوّل المادة إلى تقرير أو منشور أو مهام وغيرها، دون برومبت طويل في كل مرة.

- تدعم النصوص والمحتوى المنسوخ والملفات التي يستطيع المضيف قراءتها، والروابط عندما تتوفر أداة قراءة.
- تفهم الطلبات الطبيعية والأوامر المختصرة؛ لا يلزم حفظ أسماء الأوامر.
- تحافظ على لغة المستخدم وتنفّذ الطلب الواضح دون أسئلة زائدة.
- تحتوي على 12 إجراءً مستقلًا يمكن توسيعها.
- تفصل طلب المستخدم عن أي تعليمات مدسوسة داخل مصدر التحويل.

**الإصدار الأول مهارة، وليس تطبيق ويب أو محرك توليد مستقلًا.** نموذج المساعد ينفّذ التحويل. سكربت Python اختياري للتثبيت والتحقق وتجهيز الطلبات؛ لا يتصل بخدمة ذكاء اصطناعي ولا ينتج تحويلات بمفرده. لا يلزم مفتاح API إضافي للمهارة، وقد يخضع استخدام النموذج لاشتراك أو تكاليف المضيف.

## التثبيت

نزّل ملفات [المستودع على GitHub](https://github.com/turky015-oss/OmniTransform) عبر **Code → Download ZIP** ثم فك الضغط، أو انسخه:

```bash
git clone https://github.com/turky015-oss/OmniTransform.git
cd OmniTransform
```

السكربتات تحتاج Python 3.10 أو أحدث ولا تحتاج مكتبات خارجية.

### Codex

```bash
python3 scripts/omnitransform.py validate
python3 scripts/omnitransform.py install
```

يُنسخ مجلد المهارة إلى `$CODEX_HOME/skills/omnitransform`، أو إلى `~/.codex/skills/omnitransform` عند غياب المتغير. افتح مهمة جديدة، أو أعد تشغيل المضيف إذا لم تظهر المهارة. المثبّت يرفض الكتابة فوق نسخة موجودة؛ حدّث النسخة يدويًا بعد مراجعة اختلافاتها والاحتفاظ بتعديلاتك.

لتجربة التثبيت في مسار آخر:

```bash
python3 scripts/omnitransform.py install --destination /path/to/skills/omnitransform
```

هذا مثال لمسار تختاره؛ يجب أن يكون المجلد النهائي غير موجود وأن يسمح المضيف باكتشافه.

### تثبيت يدوي أو مضيف آخر

انسخ **مجلد `skills/omnitransform` كاملًا** إلى مجلد المهارات الذي يدعمه المضيف. لا تنسخ `SKILL.md` وحده؛ يحتاج ملفات الإجراءات والمراجع. إن كان المضيف لا يدعم المهارات، زوّده بالملف والمراجع المناسبة صراحة، مع مراعاة حدود سياقه. توافق الأزرار والملفات والروابط يعتمد على أدواته.

## الاستخدام

داخل Codex، استدعِ المهارة وأرفق المادة أو الصقها:

```text
$omnitransform /لخص
[المحتوى]
```

أو اكتب طلبًا طبيعيًا:

```text
$omnitransform حول هذا إلى بوست لإكس:
أطلقت المكتبة نادي قراءة مجانيًا يجتمع كل خميس الساعة السادسة مساءً.
```

عند إرسال مادة دون تحديد النتيجة، تقترح المهارة خيارين أو ثلاثة مناسبين وتعرض:

**لخص | اكتب | أعد الصياغة | حلل | تقرير | بوست | مهام | سكريبت | ترجم | اختصر | اشرح | استخرج**

تظهر كخيارات نصية في المضيف العادي، أو خيارات تفاعلية إن دعمها. ليست أزرارًا مضمونة في كل تطبيق. اختر الاسم أو الأمر لإكمال العملية على المادة السابقة. أوامر `/…` اختصارات داخل المحادثة وليست أوامر shell.

### تجهيز طلب من ملف نصي

اختياري: يجهز هذا الأمر طلبًا للصقه في المساعد، **ولا يولّد نتيجة التحويل**:

```bash
python3 scripts/omnitransform.py prepare --action /مهام --file examples/meeting.txt
python3 scripts/omnitransform.py prepare --request "حول هذا إلى بوست لإكس" --text "افتتاح نادي القراءة يوم الخميس"
python3 scripts/omnitransform.py list
```

يدعم المساعد أيضًا `--stdin`. قارئ السكربت محدود بملفات UTF-8 النصية حتى 2 MiB؛ هذا حد لأداة التجهيز فقط. أرفق PDF وDOCX والصور في المضيف مباشرة، حيث تتوقف قراءتها على الأدوات المتاحة. أرسل الرابط في المحادثة؛ السكربت لا يجلب صفحات الويب. عند تعذر قراءة المصدر توضح المهارة ذلك وتطلب النص أو نسخة قابلة للقراءة.

## الأوامر المتوفرة

| الأمر | الوظيفة |
|---|---|
| `/لخص` | تلخيص يحفظ الأفكار والحقائق الأساسية. |
| `/اكتب` | إنشاء محتوى جديد اعتمادًا على المدخلات. |
| `/اعد_الصياغة` | صياغة أوضح وأكثر احترافية دون تغيير المعنى. |
| `/حلل` | استخراج الأفكار والملاحظات والاستنتاجات. |
| `/تقرير` | تقرير منظم ومهني من المادة المتاحة. |
| `/بوست` | منشور متكيف مع المنصة والجمهور. |
| `/مهام` | خطوات عملية مع المسؤول والمواعيد إن وردت. |
| `/سكريبت` | سيناريو أو سكريبت فيديو جاهز للاستخدام. |
| `/ترجم` | ترجمة تحفظ المعنى والنبرة والمصطلحات. |
| `/اختصر` | نص أقصر يحافظ على الرسالة الأساسية. |
| `/اشرح` | شرح مبسط وواضح متكيف مع القارئ. |
| `/استخرج` | استخراج الأسماء والأرقام والتواريخ والروابط والقرارات. |

تُقبل `/أعد_الصياغة` كذلك. الفرق بين **لخص** و**اختصر**: التلخيص يقدم أهم المعلومات، أما الاختصار فينتج نسخة أقصر تحل محل النص نفسه. في الترجمة تُستخدم لغة الهدف المطلوبة؛ إن لم تُحسم من السياق تسأل المهارة عن اللغة فقط.

## أمثلة عملية

| طلبك | النتيجة المتوقعة |
|---|---|
| «عطني أهم الأشياء في الملف» | ملخص وأهم الحقائق دون تكرار |
| «حول هذا إلى بوست لإكس» | منشور موجز يتكيف مع إكس |
| «خله رسمي وواضح» | صياغة محسنة تحافظ على المعنى |

| «ترجم هذا إلى الإنجليزية ثم اختصره» | نص إنجليزي موجز يحافظ على الرسالة |
| «استخرج الأرقام بصيغة JSON» | JSON صالح بالقيم والوحدات الواردة |
| «اشرح هذا لطالب مبتدئ» | شرح بسيط بمثال مناسب |

تجربة جاهزة: أرفق [محضر الاجتماع](examples/meeting.txt) واطلب `/مهام`. قارن النتيجة بـ[أمثلة النتائج](examples/results.md). الأمثلة نتائج مرجعية مكتوبة للتوضيح وليست مخرجات سكربت Python أو ضمانًا لتطابق كل نموذج حرفيًا. راجع [حالات التقييم](tests/behavioral.md) لاختبار المهارة داخل مضيفك.

## إضافة Action جديدة

1. أنشئ ملفًا داخل `skills/omnitransform/actions/` يوضح الهدف، وشكل الناتج، وما يجب الحفاظ عليه. أعد استخدام القواعد المشتركة بدل نسخها.
2. أضف سجلًا في `actions/registry.json` بمعرّف إنجليزي فريد وأمر واسم ووصف ومرادفات ومسار الملف. مثال لإجراء جديد:

```json
{
  "id": "email",
  "command": "/بريد",
  "label": "بريد",
  "description": "صياغة رسالة بريد من المادة المقدمة.",
  "aliases": ["email"],
  "path": "actions/email.md"
}
```

3. أضف رابط الإجراء في جدول `SKILL.md` وخيارًا في Quick Actions، وحدّث جدول README. هذه الخطوة تجعل الإجراء قابلًا للاكتشاف من النموذج، وليس فقط من السكربت.
4. أضف حالة تقييم واقعية، ثم شغّل التحقق والاختبارات. أوامر `list` و`prepare` و`install` تقرأ السجل تلقائيًا؛ لا تحتاج تعديل الموجّه البرمجي.

ينتج الأمر الأخير `dist/OmniTransform-0.1.0.zip` جاهزًا للإرفاق بإصدار GitHub، ويرفض استبدال أرشيف موجود. يحتوي على المشروع والمهارة، ويستبعد `.git` وملفات البيئة وذاكرة Python المؤقتة. يعمل GitHub Actions عند الدفع وفتح Pull Request. اختبارات Python تتحقق من التوجيه الصريح والتثبيت والمراجع والحزمة؛ لا تثبت جودة إجابات نموذج بعينه. التقييم السلوكي يُجرى داخل المضيف بحسب `tests/behavioral.md`.
