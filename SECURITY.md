# Security and privacy

The Python helpers run locally and do not make network requests. They do not
execute source content. Prepared requests label source material separately
from user instructions; the skill also instructs the host to treat document and
webpage instructions as untrusted source data. This reduces ambiguity but is
not a guarantee against every model-level prompt injection.

AI transformations run in the user's host and follow its data handling and tool
permissions. Do not submit secrets or confidential files to public issues.

For a security concern, contact the repository maintainer privately using the
contact channel on their GitHub profile. If private vulnerability reporting is
enabled on the published repository, use its Security tab. Do not publish
working exploits or private data in an issue before coordinated disclosure.
